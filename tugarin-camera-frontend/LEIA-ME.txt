TUGARIN - FRONTEND DA CAMERA (ADAPTADO)

Esta pasta contém a tela de monitoramento/câmera reaproveitada do projeto CRUD-PI antigo e adaptada para conversar com o backend novo.

ARQUIVOS
- index.html: tela da câmera.
- camera.css: estilos específicos da tela.
- camera.js: acesso à câmera, captura automática a cada 2 segundos, chamada à API e desenho das caixas de detecção.
- assets/: CSS geral e ícones da interface antiga.

COMO TESTAR LOCALMENTE
1. Deixe o backend novo rodando em http://localhost:3000.
2. No backend, confirme que ROBOFLOW_API_KEY está configurada no .env. Nunca compartilhe essa chave.
3. Sirva esta pasta por um servidor local (por exemplo, Live Server do VS Code). Não abra o HTML com duplo clique: o navegador pode bloquear o acesso à câmera.
4. Se o Live Server usar uma origem diferente de localhost:3000, inclua essa origem em CORS_ORIGINS no .env do backend e reinicie a API. Exemplo para Live Server padrão: CORS_ORIGINS=http://127.0.0.1:5500,http://localhost:5500
5. Faça login pela aplicação atual usando POST /api/auth/login e copie o campo token da resposta.
6. Cole o token no campo “Token de acesso (JWT)” desta tela e clique em “Iniciar câmera”.
7. Autorize o navegador a usar a câmera.

INTEGRAÇÃO
- Endpoint chamado: POST /api/imagens/analisar
- Cabeçalho: Authorization: Bearer <token>
- Corpo JSON: { "imagem": "data:image/jpeg;base64,..." }
- A página chama a API a cada 2 segundos e mostra a quantidade e as caixas das predições retornadas.
- Endereço padrão da API: http://localhost:3000 (editável na tela).

IMPORTANTE
- Esta é uma tela independente em HTML/CSS/JavaScript puro para facilitar o teste. Não foi convertida para React nem conectada à navegação/login do frontend atual.
- Os links inferiores são apenas visuais nesta versão independente.
- Para usar no frontend definitivo, integrar a tela ao roteamento e ao mecanismo de autenticação já existente, substituindo o campo manual de token pelo token gerenciado pela aplicação.
- O acesso à câmera exige localhost ou HTTPS e permissão do usuário.
- A tela não grava automaticamente as detecções no MongoDB; apenas mostra a resposta do serviço de análise.
